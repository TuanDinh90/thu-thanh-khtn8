# Thủ Thành KHTN 8

Game ôn tập KHTN 8 gồm hai màn, chạy hoàn toàn trên trình duyệt (một file `index.html`, không cần build).

- **Màn 1:** bảo vệ căn cứ, trả lời câu hỏi để bắn thiên thạch.
- **Màn 2:** sửa chữa phi thuyền với 50 câu hỏi, có bấm giờ và kỷ lục.
- Nút **Bỏ qua màn** cần mật khẩu (đặt trong `index.html`, biến `SKIP_PASSWORD`).

## Chạy thử trên máy

Mở `index.html` bằng trình duyệt.

## Deploy lên Vercel

1. Đẩy thư mục này lên một repo GitHub.
2. Vào vercel.com, chọn **Add New → Project**, chọn repo, giữ nguyên cấu hình (Framework: Other, không cần build).
3. Bấm **Deploy**. Mỗi lần push lên nhánh `main` Vercel sẽ tự deploy lại.
